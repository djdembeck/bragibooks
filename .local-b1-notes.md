## Engine protocol facts (v2.1.1, re-verify against new release)
- Job file: schema_version 1; inputs[]; input_supplied {title, subtitle?, authors[], narrators[],
  series_name?, series_position?, description?, genres[], year? (u32)}; overrides (same fields);
  output_root; path_format. No input_provider in B1 (supplied-only).
- capabilities: schema_version, resolver_version, path_tokens[{token,label,description,example,
  values,required_fields,example_fields}], field_policy {values, writable_fields,
  cover_url_policy_values, chapter_policy_values}.
  Default policies: title "write", subtitle/cover_url/chapters "write" (available), rest "preserve".
- Preview: --job <file> --job-preview -> stdout JSON {schema_version, resolver_version, relative_path,
  metadata, engine}. Exact in supplied mode; non-mutating; no name reservation.
- Execute: --job <file> --machine -> stdout single JSON result; stderr progress lines.
  Result shape (M2): {schema_version, resolver_version, status, groups:[{outcome, artifacts,
  files_moved, preserved_artifacts, error?}]}. artifacts: {relative_path, ...} under output_root.
- Exit codes: 0 success, 1 general, 2 input/protocol, 3 config, 4 cover, 5 chapter.
- Staging layout under output_root (job mode): output_root/<bookid>.tmp staging dir; final name
  created inside it; engine's own no-clobber: refuses to replace existing final name (late arrival),
  collision precheck advisory for pre-existing.
  NOTE: engine publishes INTO output_root — so B1's output_root = per-job staging dir inside the
  destination dir (e.g. <dest>/<jobID>.tmp) keeps Bragi's existing workDir model.
  Final publication (staging -> dest) is B1's own race-safe gate.
- Minimum engine version for B1: 2.1.1 + the new supplied-book_id addendum (new tag TBD).

### Queue/execution flow
1. StartProcessing: load/capture snapshot, resolve destination (existing resolveDestination),
   validate format against capabilities path_tokens (server-side, cached probe), probe dirs
   (probeDestinations temp-file probe, keep), write job with snapshot, queue.
   Historical fallback: no snapshot row -> resolve via ADB now; failure -> 422 with reason
   (no silent ASIN-only legacy).
2. Dispatch: job without snapshot_version -> mark error "predates authoritative snapshots;
   re-preview and requeue" (plus startup sweep for queued legacy jobs).
3. Identity check pre-exec: server capabilities (cached) must match snapshot resolver_version
   and schema_version==1; mismatch -> job error "engine resolver changed; re-preview and requeue".
4. Execute: build job JSON {input_supplied: snapshot effective values, output_root: workDir,
   path_format, overrides?}; m4b-merge --job <tmpfile> --machine; stderr -> job log stream
   (lineStreamWriter on stderr now), stdout captured for single JSON.
5. Machine result: verify schema_version/resolver_version == snapshot; validate each artifact
   relative_path (no .., no abs, resolves under workDir via EvalSymlinks prefix check, no symlink
   escape); status succeeded -> publish all artifacts; failed -> keep staging, record
   preserved_artifacts, surface engine-diagnosed error.
6. Publish (B1's gate, no-replace, cross-device safe): for each artifact final=dest/relative_path;
   MkdirAll parent; if final exists -> collision: fail job, preserve staged tree, report
   (never overwrite, no suffixing). Same-device: rename(staged, tmpname-in-dest-parent) then
   os.Link(tmpname, final) (link fails EEXIST = collision safety); cross-device (EXDEV):
   stream-copy to tmpname in dest parent, then os.Link; delete temp on success.
   On total success: delete job staging tree.
7. Cancel: process-tree kill unchanged; engine staging partial -> delete workDir (no partial media
   claim), keep book restore (restoreBookOnCancel).
